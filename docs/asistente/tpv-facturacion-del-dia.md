# Facturación del día (TPV)

Pantalla de Facturación (`/tpv`). Es el **parte diario de lo facturado por cada método de pago**: tarjeta bancaria, tarjeta virtual, Bizum, transferencia bancaria y efectivo. El personal de tienda lo usa para **cuadrar lo que declara contra lo que calcula el sistema** a partir de las facturas y tickets.

- No es un libro de movimientos: se guarda **un total por día y método** que se compara con el calculado.
- "Efectivo" se añadió el 12/10/2026 como una fila más de este cuadre, para que el desglose de un día muestre todos los tipos de pago juntos.
- **No sustituye ni modifica la vista Efectivo**, que sigue siendo el libro de movimientos y retiradas de caja.
- Admite fotos adjuntas del parte (por ejemplo del cierre del datáfono).
