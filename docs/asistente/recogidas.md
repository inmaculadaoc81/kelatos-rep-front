# Recogidas a domicilio (Reparaciones > Recogidas)

Lista de las **recogidas a domicilio** y de las **citas para traer el equipo a la tienda**. Los eventos vienen del calendario (Google Calendar / reservas de Cal.com): **el dashboard solo los lee y actualiza su estado y detalle, nunca crea una recogida**.

## Dos tipos de evento
- **Recogida**: a domicilio.
- **Cita de tienda**: reserva (Cal.com) para traer el equipo al taller. En estas citas sí consta el DNI/CIF del cliente.

## Estados de una recogida
Pedido de recogida → Recogida Pagada / Pago pendiente / No contesta → Recogida Realizada → Recibido en local.

Se guarda quién actualizó el estado y cuándo, y puede añadirse una observación.

## Qué datos tiene cada recogida
Fecha, hora, cliente, asunto, teléfono, email, dirección, notas, estado, observaciones y tipo.

## Formulario público de recogida
El cliente completa un formulario de **confirmar recogida** con firma y fotos del equipo. Al enviarlo, el sistema manda un correo de confirmación con esa firma y esas fotos adjuntas (las de la recogida, no las del resguardo).
