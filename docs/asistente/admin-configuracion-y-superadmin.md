# Configuración y herramientas de administración

## Configuración (solo rol administrador)
Lista de **usuarios** del dashboard: nombre, email, rol, si es técnico y estado.

## Admin (solo superadmin)
- **Eliminar Registros**: borrado controlado de registros reales (reparaciones, clientes, alquileres, ventas, facturas manuales). Se elige la tabla, se busca el registro, se ve completo antes de borrar y el **motivo del borrado es obligatorio**. Queda constancia del borrado.
- **Backups**: copias de seguridad de la base de datos. **Backup ahora** solicita una copia (tarda hasta un minuto en aparecer) y **Restaurar** restaura una (pide una clave de confirmación y escribir un texto para continuar). Hay historial de restauraciones. Restaurar es una acción grave: sustituye datos.

## Mi perfil
Muestra la cuenta (email y rol), la ficha de empleado si existe, y **Cerrar sesión**.
